# Portfólio — Isabela Simião

Site de uma página em HTML, CSS e JS puros, pronto para o GitHub Pages.
Programado em parceria com o Claude.

## Como trocar os placeholders por imagens

Salve cada imagem com o nome abaixo (`.jpg`, `.png` ou `.webp`) na pasta indicada.
O site encontra o arquivo sozinho, sem precisar mexer no código.

| Arquivo | Onde aparece | Tamanho ideal |
|---|---|---|
| `assets/img/sobre.jpg` | Seção Sobre | 1200×1200 |
| `assets/img/cases/a-1.jpg` … `a-3.jpg` | AcessiLab: prints do app | 1080×1920 (celular) |
| `assets/img/cases/b-1.jpg`, `b-2.jpg` | Requisições de RH | 1600×1000 |
| `assets/img/cases/c-1.jpg`, `c-2.jpg` | 132 aditivos | 1600×1000 |
| `assets/img/cases/d-1.jpg`, `d-2.jpg` | Agentes Copilot | 1600×1000 |
| `assets/img/cases/e-1.jpg`, `e-2.jpg` | Carreira artística | 1600×1000 |

Lembrete: nos cases 02 a 06, use apenas prints **sem dados pessoais** (LGPD).

## Estrutura
```
index.html        conteúdo
css/style.css     visual (cores no topo, em :root)
js/main.js        animações, menu e placeholders
assets/           foto, favicon e imagens dos cases
```
